# Cockpit screen frames (throwaway)

This folder is **not** the product. It is a low-fidelity inventory of cockpit screens, for scanning before we draw in Paper. Do not treat it as `/chat`.

## How to open

Open the HTML file in a browser. No build step.

`app/prototype/cockpit-screens.html`

4. **Second call / allocated stock** — right: Munich Motion transcript (`in_stock_allocated`).
5. **Claim vs record** — right: Claim | Supplier Record + Landed Cost.
